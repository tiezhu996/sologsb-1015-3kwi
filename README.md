# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘，字符级并排比较与上下处差异定位。
- 宋刻本逐字标注批次合流（见下节）。
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、检查记录和版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。

## 宋刻本批次合流

在“宋刻本合流”页粘贴逐字标注批次（JSON）。合流规则：

- **版本快照只管来源正文**：批次保存来源正文与导入时当前稿正文；平仄、韵组、停顿和对仗建议一律先作候选，不直接覆盖当前稿。
- **正文改动后标注重算**：当前稿正文一改，旧位置标注按行、字两级三向对齐搬迁；只有真正改过（或新增）的字转“待复核”，其旧标注/来源候选保留，别处照旧。
- **两边同改同一句**：在“快照 / 宋刻本 / 当前稿”三行对照中并列保留，逐句选定来源；未全部选定前执行合流会失败，且不会改动当前稿。
- **失败可重试**：批次和已确认的冲突选择、对仗决定都持久保留，重试沿用同一批次，不重复生成。
- **对仗建议**：合流前逐项接受/拒绝，仅接受项按合流后的新行号写入。
- **撤销**：整次合流是一次可撤销提交，撤销可回到合流前（批次仍保留）。
- **异文对照与导出**：待复核数量、来源（批次名/正文改动/正文新增）显示在异文并排页与导出的 Markdown 校对稿中。

批次报文示例：

```json
{
  "sourceName": "宋蜀刻本",
  "sourceRef": "卷三 · SN-001",
  "text": "春眠不觉晓，\n处处闻啼鸟。\n夜阑风雨声，\n花落知多少。",
  "marks": { "2:1": { "tone": "平", "rhyme": "", "pauseAfter": false, "basis": "《广韵》", "note": "阑，平声寒韵" } },
  "antithesis": [ { "leftLine": 1, "rightLine": 2, "note": "次联候选对仗" } ]
}
```

`marks` 的键为 `行:字`（从 0 起，不计标点）。点“填入示例批次”可直接试用。

## 技术栈

- Angular 19（standalone components）
- TypeScript
- NG-ZORRO
- RxJS 与 Angular Signals
- Less
- 原生 `localStorage`

## 本地开发

```bash
npm install
npm start
```

浏览器打开终端提供的本地地址。

## 合流规则验证

无需浏览器，直接在 Node 下验证三路合流引擎与 Store 行为（共 18 项断言）：

```bash
npm run verify
```

## 生产构建

```bash
npm run build
```

生产文件位于 `dist/app/browser/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。
